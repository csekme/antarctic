# M5 — Production deploy & observability

A milestone egy nagy PR-ben szállítja a production-ready stack összes részét: security header baseline, healthcheck + trace ID + struktúrált JSON log, proxy-aware HTTPS, Redis-backed rate-limit store, és multi-stage Docker image PHP-FPM + nginx párossal. A M4.b.5-re tervezett Redis-store follow-up ide csatlakozott.

## Cél

A backend kiszolgálható legyen production környezetből úgy, hogy
1. minden response baseline security header-ekkel megy ki,
2. minden request trace ID-vel korrellálható a logokban (12-factor JSON stdout),
3. K8s probe-ok (`/api/v1/healthz`, `/api/v1/readyz`) kiszolgáltak,
4. TLS-terminating proxy mögött is helyesen detektáljuk a `https://` sémát és redirectelünk,
5. rate-limit bucket-eket workerek között Redis-en megosztjuk,
6. egyetlen `docker compose -f docker-compose.prod.yml up -d --build` paranccsal felugrik a teljes stack opcache+JIT-tel, route cache-elt PHP-vel.

## Új fájlok

### M5.a — Security headers middleware

- [src/Framework/Http/SecurityHeadersMiddleware.php](../src/Framework/Http/SecurityHeadersMiddleware.php) — PSR-15 middleware. Default header-ek: `Strict-Transport-Security` (csak HTTPS-en), `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `Referrer-Policy: strict-origin-when-cross-origin`, `Permissions-Policy`, `Content-Security-Policy: default-src 'self'; frame-ancestors 'none'; ...`, `X-Permitted-Cross-Domain-Policies: none`. Downstream-en már meglévő header-eket nem ír felül.
- [src/config/security-headers.php](../src/config/security-headers.php) — env-overridable: `APP_CSP`, `APP_PERMISSIONS_POLICY`, `APP_HSTS_MAX_AGE`, `APP_HSTS_PRELOAD`, `APP_TRUST_PROXY`.
- [src/tests/Framework/Http/SecurityHeadersMiddlewareTest.php](../src/tests/Framework/Http/SecurityHeadersMiddlewareTest.php) — 7 teszt.

### M5.b — Healthcheck endpoint-ok, trace ID, JSON log

- [src/Framework/Logging/TraceIdHolder.php](../src/Framework/Logging/TraceIdHolder.php) — request-szintű korrelációs ID static holder (worker reset friendly).
- [src/Framework/Logging/TraceIdProcessor.php](../src/Framework/Logging/TraceIdProcessor.php) — Monolog processor: `extra.trace_id`-t stamp-eli minden log record-ra.
- [src/Framework/Logging/LoggerFactory.php](../src/Framework/Logging/LoggerFactory.php) — Monolog logger JSON formatterrel `php://stdout`-ra. `fromEnv()` honorálja `APP_LOG_LEVEL` / `APP_LOG_CHANNEL`.
- [src/Framework/Http/TraceIdMiddleware.php](../src/Framework/Http/TraceIdMiddleware.php) — inbound `X-Request-Id` accept (whitelist regex), különben `bin2hex(random_bytes(16))`. Request attribute + holder + response header.
- [src/Framework/Controllers/Api/V1/HealthController.php](../src/Framework/Controllers/Api/V1/HealthController.php) — `GET /api/v1/healthz` (liveness, mindig 200) és `GET /api/v1/readyz` (readiness, PDO `SELECT 1`; 503 + problem+json hibára).
- [src/tests/Framework/Logging/TraceIdProcessorTest.php](../src/tests/Framework/Logging/TraceIdProcessorTest.php), [src/tests/Framework/Logging/LoggerFactoryTest.php](../src/tests/Framework/Logging/LoggerFactoryTest.php), [src/tests/Framework/Http/TraceIdMiddlewareTest.php](../src/tests/Framework/Http/TraceIdMiddlewareTest.php), [src/tests/Framework/Controllers/Api/V1/HealthControllerTest.php](../src/tests/Framework/Controllers/Api/V1/HealthControllerTest.php) — 15 új teszt.

### M5.c — Proxy-aware HTTPS

- [src/Framework/Http/RequestScheme.php](../src/Framework/Http/RequestScheme.php) — centralizált `isHttps()` helper, opt-in `X-Forwarded-Proto` honour-ral (`APP_TRUST_PROXY`).
- [src/Framework/Http/HttpsRedirectMiddleware.php](../src/Framework/Http/HttpsRedirectMiddleware.php) — opcionális 301 HTTP→HTTPS, `APP_FORCE_HTTPS=1` mögött; `OPTIONS` preflight átengedve; `/api/v1/healthz` + `/api/v1/readyz` excluded prefix (loopback probe friendly).
- [src/tests/Framework/Http/RequestSchemeTest.php](../src/tests/Framework/Http/RequestSchemeTest.php) + [HttpsRedirectMiddlewareTest.php](../src/tests/Framework/Http/HttpsRedirectMiddlewareTest.php) — 11 új teszt.
- `SecurityHeadersMiddleware` refactor: a beágyazott `isHttps()` private metódus átkerült a megosztott `RequestScheme` helperbe.

### M5.d — Redis-backed RateLimitStore

- [src/Framework/Http/RateLimit/RedisLike.php](../src/Framework/Http/RateLimit/RedisLike.php) — minimális protokoll (predis / phpredis / saját adapter ide implementálódik).
- [src/Framework/Http/RateLimit/RedisStore.php](../src/Framework/Http/RateLimit/RedisStore.php) — `RateLimitStore` impl, `{prefix}{key}` namespace-eléssel.
- [src/Framework/Http/RateLimit/PredisAdapter.php](../src/Framework/Http/RateLimit/PredisAdapter.php) — `predis/predis` adapter. Az `INCR + EXPIRE` atomicity-t Lua scripttel (`EVAL`) garantálja: első INCR-kor (count==1) áll be a TTL, későbbi hit-ekkor nem nyúl hozzá.
- [src/tests/Framework/Http/RateLimit/RedisStoreTest.php](../src/tests/Framework/Http/RateLimit/RedisStoreTest.php), [PredisAdapterTest.php](../src/tests/Framework/Http/RateLimit/PredisAdapterTest.php) — 8 új teszt (fake `RedisLike`, predis client mock).

### M5.e — Multi-stage Docker

- [docker/php-fpm/Dockerfile](../docker/php-fpm/Dockerfile) — 3-stage: `vendor` (composer install --no-dev cached layer), `build` (route cache + OpenAPI dump warm), `runtime` (php:8.2-fpm-alpine + pdo + opcache, non-root www-data).
- [docker/php-fpm/conf.d/opcache.ini](../docker/php-fpm/conf.d/opcache.ini) — opcache + tracing JIT 100MB; `validate_timestamps=0` (re-deploy = új image).
- [docker/php-fpm/conf.d/php-prod.ini](../docker/php-fpm/conf.d/php-prod.ini) — `expose_php=Off`, `display_errors=Off`, error log stderr-re, conservative memory + upload limit-ek.
- [docker/php-fpm/www.conf](../docker/php-fpm/www.conf) — FPM pool (`dynamic`, 16 max children, 1000 max_requests), `pm.status_path` + `ping.path`.
- [docker/nginx/Dockerfile](../docker/nginx/Dockerfile) + [docker/nginx/default.conf](../docker/nginx/default.conf) — `nginx:1.27-alpine`, FastCGI upstream php-fpm:9000-re, SPA fallback `/app/`, FPM status internal-only, dotfile-block.
- [docker-compose.prod.yml](../docker-compose.prod.yml) — `php-fpm` + `nginx` + `postgres:16-alpine` + `redis:7-alpine`, healthcheck-ek minden service-en, named volume DB-perzistálásnak.

## Pipeline sorrend (Bootstrap.php)

```
SecurityHeaders → TraceId → ErrorHandler → [HttpsRedirect] → Cors → [RateLimit] → [Auth] → LegacyDispatcher
```

A szögletes zárójelben lévő middleware-ek env-flag mögött opcionálisak. A sorrend tudatos:
- **SecurityHeaders** legkívül, hogy a downstream 5xx error response-ok is megkapják a header baseline-t.
- **TraceId** az ErrorHandler ELŐTT — különben a `Throwable` log record-ja kimaradna a `trace_id`-ből (a holder már törölt lenne).
- **HttpsRedirect** és **CORS** között: a preflight `OPTIONS` redirect-mentes (RFC: nincs body, csak header negotiation).

## Mit *nem* tartalmaz ez a PR

- **AuthController cookie `Secure` flag proxy-aware** — jelenleg `APP_ENV !== 'local'` alapján dől el. A `RequestScheme` helper most már elérhető, de a controller refactor M3.d follow-up (container-injection minta).
- **OpenTelemetry SDK** — a PLAN.md "opcionális" jelzéssel említi; struktúrált JSON log + trace ID együtt elég a 12-factor observability minimumhoz. Ha kell, külön PR-ben.
- **phpredis adapter** — csak `PredisAdapter`-t szállítunk. `RedisLike` interface kompatibilis bármilyen `ext-redis`-alapú impl-lal; egy `PhpRedisAdapter` ~30 LOC.

## Deployment receptúra (production)

```bash
# 1. Image build (repo root):
docker build -f docker/php-fpm/Dockerfile -t antarctic-fpm .
docker build -f docker/nginx/Dockerfile -t antarctic-nginx .

# 2. Stack indítás:
DATABASE_PASSWORD=secret docker compose -f docker-compose.prod.yml up -d --build

# 3. Migrációk az új containerben:
docker exec antarctic-fpm vendor/bin/doctrine-migrations migrations:migrate --no-interaction

# 4. Smoke test:
curl -fsS http://localhost/api/v1/healthz   # {"status":"ok"}
curl -fsS http://localhost/api/v1/readyz    # {"status":"ready","checks":{"database":"ok"}}
```

A TLS-terminating ingress / load balancer mögött kapcsold be a `APP_TRUST_PROXY=1` és `APP_FORCE_HTTPS=1` env változókat.
