# M2.a — Kulcsgen + TokenService + refresh_tokens tábla

**Cél**: a JWT auth alapinfrastruktúrája — RS256 kulcspár generátor (`bin/console keys:generate`), `TokenService` (access issue + verify, refresh issue + rotation + reuse detection), `refresh_tokens` tábla és PDO repository. **Még nincs middleware vagy endpoint** — azt M2.b szállítja.

## Új fájlok

### Auth réteg
- [src/Framework/Auth/TokenService.php](../src/Framework/Auth/TokenService.php) — `issueAccessToken`, `verifyAccess`, `issueRefreshToken`, `rotateRefresh`, `revokeRefresh`. Reuse detection: ha egy revokált refresh-t újra próbálnak, a teljes `family_id` revokálódik.
- [src/Framework/Auth/RefreshTokenRepository.php](../src/Framework/Auth/RefreshTokenRepository.php) — PDO CRUD a `refresh_tokens` táblán. Prepared statementek, sqlite/postgres/mariadb-kompatibilis SQL.
- [src/Framework/Auth/JwtConfigFactory.php](../src/Framework/Auth/JwtConfigFactory.php) — `Lcobucci\JWT\Configuration` builder, RS256-ra korlátozva. Inline PEM (env) vagy fájl-elérési út.
- [src/Framework/Auth/SystemClock.php](../src/Framework/Auth/SystemClock.php) — triviális PSR-20 óra impl (`Psr\Clock\ClockInterface`).

### Console
- [src/bin/console](../src/bin/console) — CLI entry point (executable).
- [src/Framework/Console/Command.php](../src/Framework/Console/Command.php) — parancs interfész.

## Biztonsági jegyzetek

- Az access token claim-jeiben **NINCS PII** (csak `sub` = userId, `roles`, `iat`, `exp`, `iss`, `aud`, `jti`).
- A refresh token a kliensnél **plain string**; szerveren csak `SHA-256(token)` hash tárolódik. Token lopás esetén a támadó nem tudja a hashből visszafejteni az értéket.
- A `family_id` (UUID) köt össze egy login-szekcióhoz tartozó összes rotált refresh tokent. Reuse detection: ha egy revokált tokent használnak, az egész család revokálódik.
- A private key fájl mode kötelezően `0600`. A `keys:generate` `--force` nélkül soha nem ír felül meglévő kulcsot.
