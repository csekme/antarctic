# M1.b — CORS + RFC 7807 + content negotiation

**Cél**: a pipeline elejére bekerül a hibakezelő és a CORS allow-list middleware. A `/api/*` és `Accept: application/json` kliensek `application/problem+json` envelope-ot kapnak, a böngésző HTML hibaoldalt.

## Új fájlok

- [src/config/cors.php](../src/config/cors.php) — allow-list (origins, methods, headers, credentials, max-age). `CORS_ALLOWED_ORIGINS` env-változó felülírja az origins listát (separate deploy módhoz).
- [src/Framework/Http/CorsMiddleware.php](../src/Framework/Http/CorsMiddleware.php) — PSR-15: same-origin pass-through, OPTIONS preflight short-circuit (204), allow-list ellen ismeretlen origin → 403, wildcard (`*`) támogatott.
- [src/Framework/Http/ContentNegotiation.php](../src/Framework/Http/ContentNegotiation.php) — `wantsJson()` heurisztika: `/api/*` path → JSON; egyébként `Accept` header q-érték összevetés JSON vs HTML között.
- [src/Framework/Http/ErrorHandlerMiddleware.php](../src/Framework/Http/ErrorHandlerMiddleware.php) — Throwable boundary; status mapping (4xx-et megtart, minden más → 500); RFC 7807 `application/problem+json` az API kliensnek, minimal HTML egyébként; `debug` módban `exception/file/line` visszakerül a payloadba; 5xx-eket PSR-3 loggerre küld.
- [src/tests/Framework/Http/CorsMiddlewareTest.php](../src/tests/Framework/Http/CorsMiddlewareTest.php) — 5 teszt (pass-through, preflight allowed/rejected, decorate, wildcard).
- [src/tests/Framework/Http/ErrorHandlerMiddlewareTest.php](../src/tests/Framework/Http/ErrorHandlerMiddlewareTest.php) — 6 teszt (pass, JSON-by-path, JSON-by-accept, HTML, 500-mapping/leak-guard, debug payload).
- [src/tests/Framework/Http/ContentNegotiationTest.php](../src/tests/Framework/Http/ContentNegotiationTest.php) — 6 teszt (`/api/`, legacy query string, HTML vs JSON q-rangsor, +json, üres Accept).

## Módosítások

- [src/Framework/Bootstrap.php](../src/Framework/Bootstrap.php) — pipeline most: `ErrorHandler → Cors → LegacyDispatcher`. A globális `set_exception_handler` eltávolítva, a middleware veszi át. `Config::show_errors()` adja a debug flag-et.
- [src/phpstan.neon.dist](../src/phpstan.neon.dist) — `ROOT_PATH` definíciója `html/index.php`-ben történik a Bootstrap include előtt; targeted ignore a Bootstrap.php-ra.

## Verifikáció

- **PHPUnit**: 32/32 zöld (15 → 32, +17 új teszt).
- **PHPStan level 1**: 21 hiba — **változatlan** az M1.a utáni szinthez képest. 0 új hiba az új kódból.
- **`gitnexus_detect_changes`**: a változott szimbólumok (Dispatcher, Response) az M1.a-ban már nyilvántartottak; a teljesen új `Framework/Http/*` osztályok még nincsenek indexelve (`gitnexus analyze` futtatása esedékes).
